  Key points:
    - Can use NeoPixel library, but these don't use shift registers like most so you can't string multiple strings together. This is because each LED is pre-addressed from 0-100
    - Needs a 5V power supply
    - Red is power, black is ground, green is data
    - One pixel every 100mm (~4in), total strip is 10,000mm (~32.8ft) long
